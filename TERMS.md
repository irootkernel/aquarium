This exception grants no authority to copy the repository or change source, Git state, or any other file. Orca Review otherwise relies on explicit prompt restrictions and Orca supervision rather than a capture, repository fingerprint, or technical write sandbox. Technical ability to change a file never grants authority to do so. Repository and organization policies remain authoritative.
