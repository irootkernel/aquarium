# Greeting fixture guidance

Use installed Aquarium skills and the canonical roadmap and dossier. Keep code
and documentation in English. The fixture operator supplies actual plan,
execution, correction, exact-result and commit decisions at their normal
boundaries. Do not infer an approval from this file or mark partial work achieved.

Use native Codex Workers and an independent report-only Codex Judge. The selected
technical review route is three-agent native Codex Independent Review. Preserve
original criteria, relevant checks and the normal handler approval boundaries.

## Project Configuration

`docs/roadmap/README.md` owns work identity and lifecycle. `docs/todo/` owns the
Epic execution dossier. `TESTING.md` and `Makefile` own the fixture test contract.
Aquarium release notes: CHANGELOG.md

Developer-authored commit subjects use `[FEAT]`, `[FIX]`, `[TEST]`, `[DOC]` or
`[DEV]` and a concise English imperative summary. Include the applicable
Aquarium-Workflow, Aquarium-Epic and Aquarium-Task trailers.
