# Development and Retirement Contract

The candidate removes the shared `aquarium-dev` manager, runtime installer, launcher, MCP server, producer targets and exclusive tests. Do not offer channel setup, enrollment, rebuild or service activation. Use supported installed releases and native paired skills. Production readiness still requires global Podway, Mulgae and Gaori; Dolgorae and Sanho remain optional.

This package change does not mutate installed declarations or host state. An older installed release may still expose channel tools. Native disablement, session/client settlement, exact hook removal, controller retirement and final deletion require their separately approved effect package. Preserve unresolved owners and recovery consumers. Never use broad kills, cache patches, resets, a host candidate install or historical Codex restore to force detachment.

## Retained contracts

- The source repository's host-only builder preserves `aquarium-dev-artifact-manifest/v1` as a data contract. It requires a clean disposable local-`main` clone at the selected SHA and an empty physical absolute output directory. Only the copied manifest version is stamped; file bytes, modes and digest remain commit-bound. The managed host adapter owns invocation and sealing.
- Production status retains historical `components.aquarium_dev` records and existing setup schema names. Reports no longer inspect enrollment files. `enrollment.state: retired` means the observation was retired, not that host cleanup succeeded.
- Protective production resolution still rejects executables under `.aquarium-dev`.
- One Haepari Job retains the saved spec/key, resource, lease and evidence identity through execution, reconnection, consumer cleanup, native collection/cleanup and receipt-verified export. Preparation is not acceptance.

The source repository's development specification, retirement runbook and VM guide own implementation and host sequencing. Historical producer/controller contracts remain in Git and retained ADR/dossier history; they are not current setup instructions.
